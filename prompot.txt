Problem Statement: Write a 2d graphics editor using * and  _.

1. Write functions to draw a circle, rectangle, line, and triangle.
2. You should be able to       add objects to the picture,       delete objects from the picture, and        modify objects in the picture.
3. Use a 2d array of characters to store the picture.
4. Write a function to display the picture.
5. Requirements:
   * Create a repository in GitHub.
   * Submit the link to the GitHub repository in Moodle. (In the online text field provided in the assignment)
   * Daily push to GitHub is mandatory.
answer 
Write functions to draw a circle, rectangle, line, and triangle using standard math (like Bresenham's algorithms).

Use a 2D char array for the canvas, including a bounds-safe "plot" function to prevent crashes.

Create functions to add, delete, and modify shapes using an ID system.

Write a display() function to print the canvas.

The main() function must run a demo that sequentially adds, deletes, and modifies shapes, displaying the result after each step.

At the end, briefly acknowledge my assignment rules: I must create a GitHub repo, do daily pushes, and submit the link on Moodle.
